# PLC Learn: TIA Portal

Gamified static web app (`index.html`, `app.js`, `style.css`); lessons in `content\`, SVG figures in `figures*.js`, ladder simulator in `sim.js`.
It is an installable web app (PWA) and also runs inside Electron on the desktop.

- Run: open `index.html` in a browser
- Live site: https://danny3929.github.io/plc-learn/
- Publish changes: run `.\publish.ps1 "message"` (bumps the cache, pushes, waits for the site)
